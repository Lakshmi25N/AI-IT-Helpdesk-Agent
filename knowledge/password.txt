IT HELPDESK - PASSWORD AND ACCOUNT TROUBLESHOOTING

Problem: User forgot their password.

Recommended procedure:
1. Use the organization's official password-reset procedure.
2. Verify the user's identity if required.
3. Do not share passwords with another person.
4. Create an IT support ticket if self-service password reset is unavailable.

Problem: Account is locked.

Recommended procedure:
1. Stop repeatedly entering the password.
2. Wait for the organization's lockout period if applicable.
3. Use the official account recovery procedure.
4. Contact IT support if the account remains locked.

Security rule:
The IT Helpdesk Agent must never request or reveal a user's password.
